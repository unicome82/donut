## 스테이지 추가

Node.js 24에서 다음 명령을 실행하면 등록된 마지막 스테이지 다음부터 지정한 번호까지 추가합니다.

```sh
npm run stages:generate -- 120
npm test
```

스테이지 1은 직접 만든 튜토리얼이고, 2번부터는 생성기가 만듭니다. 현재 배치 리비전(`layoutRevision`)으로 저장된 스테이지와 해법은 유지되고, 리비전을 올리면 전부 다시 생성합니다. 두 번째 인수에 시드 정수를 넘기면 배치를 재현할 수 있습니다. 기본 시드는 `2026`입니다.

### 난이도 규칙

- 순서: 1~8번은 Easy와 Normal을 번갈아 배치하고, 9번부터 `N·E·H·N·E·N·H·E` 주기를 반복합니다. 첫 Hard는 11번입니다 (`src/game/stages/schedule.ts`).
- 트레이: Easy 12칸, Normal 10칸, Hard 8칸. 디저트 종류는 10·15·20종입니다.
- 난이도 보정: 후보 배치마다 두 봇으로 성공률을 잽니다. 숙련 봇은 필요한 디저트가 가장 가까운 줄을, 초보 봇은 맨 앞이 필요한 줄 중 아무거나 고릅니다. 목표 범위에 맞는 후보만 저장하고, 목표는 캠페인 후반으로 갈수록 조금씩 어려워집니다 (톱니형 진행).
- 제한 시간: `10초 + 디저트 수 × (Easy 1.0초, Normal 1.1초, Hard 1.2초)`를 5초 단위로 올림합니다. 남은 시간이 절반 이상이면 별 3개, 1/4 이상이면 별 2개입니다.
- 확장 없이 클리어하는 경로를 실제 게임 엔진으로 확인한 뒤 `src/game/stages/generated.json`에 저장합니다.
