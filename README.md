## 스테이지 추가

Node.js 24에서 다음 명령을 실행하면 등록된 마지막 스테이지 다음부터 지정한 번호까지 추가합니다.

```sh
npm run stages:generate -- 120
npm test
```

현재 배치 리비전으로 저장된 스테이지와 해법은 유지됩니다. 이전 리비전은 새 배치와 해법으로 갱신하며, 주문에 필요한 종류 수가 바뀌면 주문도 다시 생성합니다. 두 번째 인수에 시드 정수를 넘기면 후보의 무작위 배치를 재현할 수 있습니다. 기본 시드는 `2026`입니다.

난이도는 생성 스크립트의 순환 순서에 따라 섞입니다. 대기열 묶음과 주문 조합을 바꿔 후보를 만들고, 주문량의 절반을 여분으로 넣어 클리어 시 준비량의 약 3분의 1이 남도록 합니다. 실제 게임 엔진으로 이동·도착·픽업을 재생하고, 트레이 확장 없이 빈 트레이로 클리어하면서 해당 난이도의 트레이 사용량 범위를 충족한 배치와 해법을 `src/game/stages/generated.json`에 저장합니다. 트레이 사용량은 해법 한 경로에서 측정한 값이며, 체감 난이도는 플레이로 확인할 수 있습니다.
