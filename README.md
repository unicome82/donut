## 스테이지 추가

Node.js 24에서 다음 명령을 실행하면 등록된 마지막 스테이지 다음부터 지정한 번호까지 추가합니다.

```sh
npm run stages:generate -- 120
npm test
```

현재 배치 리비전으로 저장된 스테이지와 해법은 유지됩니다. 이전 리비전에는 난이도별 변경 사항을 적용하고 배치와 해법을 다시 생성합니다. 두 번째 인수에 시드 정수를 넘기면 후보의 무작위 배치를 재현할 수 있습니다. 기본 시드는 `2026`입니다.

Easy, Normal, Hard의 기본 트레이는 각각 20칸, 13칸, 8칸입니다. 준비량은 디저트 종류별 주문 수량과 일치합니다. 높은 난이도에서는 주문을 더 큰 묶음으로 섞고, 같은 디저트를 더 작은 단위로 나눠 대기열에 배치합니다. 확장 없이 클리어하는 경로를 실제 게임 엔진으로 확인한 뒤 `src/game/stages/generated.json`에 저장합니다.
