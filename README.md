## 스테이지 추가

Node.js 24에서 다음 명령을 실행하면 등록된 마지막 스테이지 다음부터 지정한 번호까지 추가합니다.

```sh
npm run stages:generate -- 120
npm test
```

이미 저장한 스테이지와 해법은 유지됩니다. 두 번째 인수에 시드 정수를 넘기면 새로 생성하는 후보의 무작위 배치를 재현할 수 있습니다. 기본 시드는 `2026`입니다.

난이도는 생성 스크립트의 순환 순서에 따라 섞입니다. 대기열 묶음과 주문 조합을 바꿔 후보를 만들고 실제 게임 엔진으로 이동·도착·픽업을 재생합니다. 트레이 확장 없이 클리어하고 해당 난이도의 트레이 사용량 범위를 충족한 배치와 해법을 `src/game/stages/generated.json`에 저장합니다. 트레이 사용량은 해법 한 경로에서 측정한 값이며, 체감 난이도는 플레이로 확인할 수 있습니다.
